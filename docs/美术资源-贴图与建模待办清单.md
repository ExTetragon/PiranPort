# 美术资源贴图与建模待办清单

> 状态日期：2026-10-31；工程版本：0.1.125。

当前游戏贴图共有131张PNG：112张物品图、18张方块及流体图、1张GUI背景，不含模组标志。静态资源检查未发现悬空的本模组贴图引用，后续工作主要是替换占位图、重绘效果不佳的资源和补充独立外观。

23张装备贴图的现有效果不通过，全部需要重绘，包括21个耐久装备型号和快修、损管两种普通消耗品。已有文件和来源记录作为参考保留，不能按“已经改绘”视为正式美术完成。

## 替换与验收要求

- 每批制作后同时检查原尺寸辨识度、放大后的像素边缘、透明背景、轮廓及同类对象的区分度。装备图延续现有32×32资源接口，其他对象的最终尺寸按美术方案确定。
- 替换时优先沿用现有路径，保留身份与型号映射；新增独立图标或机器纹理时同步模型引用。
- 机器需检查正面及朝向、UV、物品栏模型和世界内效果；流体需检查四种静止／流动状态，不能只凭PNG文件存在判定完成。
- 清单完成状态以实际美术确认和游戏内显示为准。文件存在、资源检查通过或完成过一轮改绘，均不代表视觉效果已通过。
