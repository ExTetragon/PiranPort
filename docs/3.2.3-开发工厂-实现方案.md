# 3.2.3 开发工厂实现方案

> 2026-10-24。0.1.90已实现开发工厂、23项配方、快修／损管普通消耗品和两个COMMON配置；0.1.91将GUI细节统一到船坞。维修、自动补血与免死触发尚未实现；实际验证范围见第10节。
> 原始资料为[策划书](策划书.pdf)3.2.3；制造事务参考[船坞方案](3.2.2-船坞-实现方案.md)，物品规则见[装备方案](2.2-装备-初步开发方案.md)，参数见[军工表](后勤-军工.xlsx)的“开发工厂参数”“装备开发”页。原始PDF保持原样。

## 1. 范围与注册

- 开发工厂使用一个工位制造武器、设备、飞机，以及仍归入设备类别的快修、损管。首批开发列表共23项：21个耐久装备型号、2种普通消耗品。
- 逐件制定配方，玩家自由搭配装备。不规定组合、配套产物或固定装配方案。
- 方块、对应物品、方块实体、菜单、配方类型和序列化器使用`piranport:development_factory`；拆除缓存组件使用`piranport:development_factory_storage`。上述注册已接入。
- 一个图纸槽、一个产物槽、12格共用材料缓存（4列×3行）、16000 mB燃油。维修标签锁定，不创建隐藏工位或额外库存。
- 方块有明确正面，支持水平朝向。方块模型与GUI延续船坞外观；功能按本方案独立配置，不沿用船坞的32000 mB容量。
- 方块物品堆叠上限1，生存拆除携带取消后的缓存。注册详情及船坞已有注册的核对结果集中记录在军工表“设施注册”页。

### 1.1 工厂自身合成

消耗4个钢锭、2个铝锭、1个空燃料桶、1个工作台、1个活塞，产出1个开发工厂。钢铝使用`c:ingots/steel`、`c:ingots/aluminum`。

布局为`SAS/BCP/SAS`：S钢锭、A铝锭、B空燃料桶、C工作台、P活塞。燃料桶必须为空，不能在合成时吞掉桶内燃油。使用`piranport:empty_fuel_barrel_shaped`检查桶内流体，预览和匹配无副作用。

列表第二行、图标下方分类行及对应悬浮共用装备分类说明：主炮·小型／中型（轻）／中型（重）／大型，鱼雷发射器·通用／潜用，装甲·小型／中型／大型；其他类别直接显示类别。中文使用不留空格的中点与全角括号，英文中点两侧留空格、括号用半角。分类过长按区域宽度省略，悬浮显示完整内容；待取产物回退预览保持一致。不增加细分筛选。

风格以[GUI规范](gui/GUI-风格规范.md)及[船坞定稿](gui/船坞-GUI-定稿.png)为基线，不复用已经废弃的三船型页签。

无适用图纸且“显示全部”关闭时，列表和所需材料为空。开启“显示全部”后可无图纸查询全部产物的图标、资料和资源需求，查询不授予制造许可。没有有效开发配方的条目仍可展示资料，但明确标“暂无开发配方”，不能伪造零成本配方。

有主动浏览选择时优先预览该项；没有主动选择且产物待取时预览产物；两者均无则预览为空。预览下方展示名称、类别和有意义的型号资料；消耗品不显示耐久和修正值。

## 3. 搜索筛选

- 仅提供装备类别多选和文字搜索，不做主炮四级、鱼雷两类、装甲三级筛选。细分字段保留在型号属性与说明中。
- 15类按武器、设备、飞机分组展示；多个类别取并集，与文字搜索条件取交集。
- 搜索中文、英文、原作名称及常见别名，忽略大小写；统一全半角、首尾空白与常用连接符的表达。
- 筛选继续受“显示全部”约束：关闭时仅在当前图纸允许的范围内筛选，开启时在全部开发目录中筛选。
- 有已应用条件时搜索图标明显变化；左键打开筛选窗口，右键立即清除筛选，保留“显示全部”勾选。
- 筛选窗口仅组织装备类别，可按三组分栏，搜索框、应用和返回固定显示。编辑使用草稿，应用后更新主列表；返回或Esc丢弃草稿。应用后修正滚动范围。
- 筛选只影响浏览，不改变任务、库存、图纸许可和资源。各玩家独立浏览，最后关闭窗口的已应用状态写回机器，不保存玩家UUID。

## 4. 图纸、开工与完工

沿用现有15项装备类别许可：主炮许可覆盖全部主炮型号，装甲许可覆盖三种附加装甲，快修和损管继续使用原有独立许可。复合图纸可覆盖多个类别，每次任务仍只消耗1张，不增加型号许可或个人研发解锁。

1. 图纸槽只接收有效装备图纸；舰船图纸、空白或无效许可拒绝。未开工时可自由取放。
2. 玩家选择条目后，服务端核对具体产物、最新配方、许可、材料、燃油、产物槽及菜单有效性。
3. 有待取产物时开发按钮仍可点，只提示先取走，不扣料。即使产物与本次相同且能够堆叠，也不允许继续开工。
4. 在副本中完成全部资源规划，成功后原子提交材料和燃油消耗，图纸槽预留1张。失败、查询和模拟均无副作用。
5. 保存唯一任务标识、产物种类与身份、产出数量、总tick、已运行tick、费用、原始弹药和投入燃油组件。费用、时长及产量均在开工时冻结。
6. 区块正常运行时推进，20 TPS按表计时；关闭GUI不影响任务，卸载或停机不补时、不强制加载区块。
7. 到时且产物槽空闲、预留图纸和目标仍有效时，扣1张图纸，生成快照指定的全部产物，清空任务、解除预留，并播放一次完成音效。
8. 耐久装备满耐久，飞机内部油量0；快修8个、损管1个，均不附加装备身份或耐久。任务结束后不自动续做。

运行中允许取走多余图纸，但必须保留最后1张；只允许补充完整许可集合相同且可正常堆叠的图纸。普通点击、分半、Shift、收集、丢弃、拖拽、漏斗和管道统一检查，禁用整槽交换。确认取消与图纸预留均不绑定开工玩家。

数据包刷新只影响新任务。目标定义丢失、预留异常或产物槽被异常数据占用时保留任务，允许恢复或取消，不重复产出或吞掉已投入资源。

## 5. 材料、取消与拆除

| 行为 | 规则 |
|---|---|
| 接收材料 | 四种本mod弹药及钢铝块、锭、粒；钢铝兼容`c:`材料标签 |
| 金属折算 | 1块=9锭=81粒，优先粒、锭、块；精确扣除，找零为本mod锭、粒 |
| 弹药折算 | 深弹1、主炮2、鱼雷2、导弹4点；按缓存顺序扣整件，末件向上取整，不找零 |
| 退款 | 取消返还净钢铝费用、开工实际消耗的原始弹药及组件、投入燃油；不消耗图纸 |
| 物品溢出 | 缓存、当前操作者物品栏、掉落；无操作者时在机器位置掉落；找零空间不足不阻止开工 |
| 燃油退款 | 尽量退入储罐，超容或组件不相容的部分销毁；确认框显示预计损失 |
| 取消确认 | 紧凑居中、默认返回、确认按钮错开首次点击位置；绑定任务标识，过期确认不得取消后来任务 |
| 生存拆除 | 取消并退款，解除图纸预留，取消后的图纸、产物、材料、燃油及浏览状态随方块物品保存；重放不恢复进度 |
| 创造拆除 | 不掉工厂方块物品，已有及退款物品散落，燃油清除，不退到创造背包 |

正常非玩家掉落参考船坞的完整容器结算，不重复散落已保存在物品中的内容；各入口只结算一次。保留当前有效数据和超额内容的恢复抽取，不为内部旧版本结构增加迁移分支。

## 6. 流体与分面自动化

储罐只接收本mod燃油，容量16000 mB，保留流体组件。GUI中用鼠标携带的兼容容器在储罐区左键注入、右键取出。世界右键以开始时储罐是否已满确定方向：未满只注入，已满只取出，尝试最大合法量；普通桶整桶转移。成功不打开GUI，无法转移则打开。

| 面 | 物品能力 | 燃油能力 |
|---|---|---|
| 顶部 | 图纸输入、输出，遵守预留和补充限制 | 无 |
| 四侧 | 材料输入、输出；抽取优先产物，其次材料 | 输入、输出 |
| 底部 | 只输出产物 | 输入、输出 |

飞机现有物品流体能力可以用于储罐交互，作为补油、取油入口，不增加专用加油槽。制造飞机的燃油成本不写入飞机油箱。模拟转移无副作用，实体移除后旧能力引用失效。

## 8. 快修与损管调整

快修、损管保留`piranport:quick_repair`、`piranport:damage_control`两个独立注册ID，改用普通物品。它们从`EquipmentItem`和耐久装备型号定义移出，保留原名称和32×32图标，不另存型号身份、耐久、三项修正、作战配置或主动效果接口，不使用伪零值占位。

两者继续加入`piranport:devices`，可另用`piranport:equipment_consumables`标识设备消耗品；该标签只决定分类与堆叠准入，不隐式赋予治疗或免死效果。

| 项目 | 快修 | 损管 |
|---|---|---|
| 物品及设备槽堆叠 | 64 | 16 |
| 每次开发产量 | 8 | 1 |
| 每次图纸消耗 | 1 | 1 |
| 普通give | 直接有效，无型号初始化 | 直接有效，无型号初始化 |
| 未来用途 | 受伤达到缺血阈值时消耗一个回复生命 | 死亡时消耗一个抵消死亡 |

其他装备的物品和装配槽仍每格1件。消耗品装入设备栏不贡献属性。创造栏分别列普通物品各一次；全部开发条目仍为23项。0.1.90已完成普通物品和核心设备槽调整，不维护内部旧型号数据迁移。

### 8.1 后续自动消耗的配置

| 配置键 | 中文名称 | 默认值 | 范围 |
|---|---|---|---|
| allowQuickRepairFromPlayerInventory | 是否允许直接消耗玩家背包中的快修 | false | COMMON |
| allowDamageControlFromPlayerInventory | 是否允许直接消耗玩家背包中的损管 | false | COMMON |

本阶段已实现配置与物品层调整，不接入自动补血、免死、原版图腾事件或主动使用效果。缺血阈值、回复量、免死后血量、同次伤害结算顺序及冷却在舰娘状态方案中单独设计，不写进单件物品。

## 9. 实施组织与验证范围

方块、方块实体、菜单、网络、配方和客户端类按既有职责目录组织；工厂专用规划、任务及浏览状态归`blockentity/developmentfactory/`，弹窗归`client/developmentfactory/`，不设置顶层功能大包。共用装备领域保持不依赖物品、GUI或方块实现。

工厂浏览目录提供轻量统一视图，组合21个型号和2个普通消耗品。装备定义和工厂浏览目录均不保留国籍字段、占位值或旧参数重载；消耗品无需耐久字段。工厂配方创建产物时分派到装备创建接口或普通物品堆。

完成音效复用已注册的`piranport:shipyard_complete`，素材为`common_craft_success`，不重复注册同一素材。真实完工在机器位置播放一次，约16格可听；打开GUI、浏览或取产物不重播。

实现与验收按以下范围划分，实际覆盖和保留的人工项见第10节：

| 范围 | 关键行为 |
|---|---|
| 注册和物品 | 工厂各注册项、空燃料桶合成、消耗品普通give／堆叠／无耐久和身份 |
| 配方 | 23项目标、四资源与产量、型号和普通物品区分、数值换算、数据包刷新快照 |
| 事务 | 同时点击只开一单、失败无副作用、图纸预留／补充／各种取出路径、完工一次 |
| 取消 | 确认绑定任务、原弹药退款、钢铝净额、燃油组件和溢出、快修整批任务无部分产出 |
| 生命周期 | 关闭GUI、正常保存、卸载不补时、生存与创造拆除、重放不恢复任务 |
| 核心准入 | 两种消耗品堆叠上限，其余设备每格1件；属性汇总不纳入消耗品 |
| 能力 | 分面权限、流体最大合法转移、纯模拟、组件保留、移除后旧引用失效 |
