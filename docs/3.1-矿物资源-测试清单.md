## A. 加载与注册

- [ ] **A1 客户端启动**
  - 步骤：`./gradlew runClient`
  - 预期：正常进入主菜单；`latest.log` 中没有 `piranport` 相关的注册错误、配方解析错误、标签解析错误。

- [ ] **A2 专用服务器启动**
  - 步骤：`./gradlew runServer`（首次需接受 EULA）
  - 预期：无注册/数据包错误；世界生成阶段无异常。

- [ ] **A3 创造模式物品栏**
  - 步骤：打开创造模式物品栏，搜索 `piranport`
  - 预期：本节新增 14 个物品（整个模组共 74 个）：矾土、铝锭、铝粒、硝土、钢锭、钢粒、原油桶、燃油桶、矾土矿、矾土块、铝块、硝土块、燃料桶、钢块。

- [ ] **A4 语言文件**
  - 步骤：切换 `en_us` / `zh_cn`，按 `F3 + H` 显示 id 后悬停
  - 预期：所有新增物品/方块/流体均有中英文名称，无 `item.piranport.*` 原始键名。

- [ ] **A5 模型与贴图**
  - 步骤：观察物品栏、手持、放置后的方块
  - 预期：新增内容无紫黑缺失贴图；流体显示半透明贴图；桶物品有图标。

- [ ] **A6 数据包重载**
  - 步骤：`/reload`
  - 预期：无配方/标签/世界生成错误。

## B. 物品与方块基础属性

- [ ] **B1 堆叠上限**
  - 步骤：分别拿取矾土、铝锭、铝粒、硝土、钢锭、钢粒
  - 预期：均为 64。

- [ ] **B2 桶堆叠**
  - 步骤：拿取原油桶、燃油桶
  - 预期：堆叠上限 1；倒出后返还空桶。

- [ ] **B3 方块硬度与抗爆**
  - 步骤：用空手/木镐/石镐分别挖掘各方块；用 TNT 测试抗爆

    | 方块 | 工具 | 大致挖掘时间 |
    |---|---|---|
    | 矾土矿 | 石镐 | ≈ 1.15 s |
    | 矾土块 | 石镐 | ≈ 1.90 s |
    | 铝块 | 石镐 | ≈ 1.90 s |
    | 硝土块 | 空手可挖 | ≈ 0.75 s（锹更快） |
    | 钢块 | 石镐 | ≈ 2.25 s |
    | 燃料桶 | 石镐 | ≈ 1.15 s |

- [ ] **B4 工具等级**

  - 预期：木镐不掉落；石镐及以上正常掉落（矾土矿受 `requiresCorrectToolForDrops` 影响）。

- [ ] **B5 硝土块工具**
  - 步骤：空手、锹、镐分别挖硝土块
  - 预期：空手可掉落；锹最快；镐也可挖但不加速。

- [ ] **B6 方块放置**
  - 步骤：放置并破坏全部新增方块
  - 预期：可正常放置/破坏；无掉落异常。

## C. 挖掘与掉落

### C.1 矾土矿

- [ ] **C1 错误工具**
  - 步骤：空手、木镐、剑挖矾土矿
  - 预期：不掉落任何物品（方块被破坏但无掉落）。

- [ ] **C2 基础掉落**
  - 步骤：用无附魔石镐挖 100 个矾土矿（可 `/fill` 放置后连续挖）
  - 预期：每次 1–3 个矾土；统计分布大致均匀。

- [ ] **C3 时运**
  - 步骤：分别用时运 I / II / III 镐挖 50 个矾土矿
  - 预期：掉落数量随等级增加；行为与原版铁矿的 `ore_drops` 一致（可与铁矿石同条件对比）。
  - 注意：`ore_drops` 可能出现高于 3 的单次掉落，属于预期。

- [ ] **C4 精准采集**
  - 步骤：用精准采集镐挖矾土矿
  - 预期：掉落 `piranport:bauxite_ore` 本身，不掉落矾土。

- [ ] **C5 时运 + 精准**
  - 步骤：用同时带时运 III 和精准采集的镐（命令附魔）挖矾土矿
  - 预期：精准采集优先，掉矿本身。

### C.2 硝土块

- [ ] **C6 空手采集**
  - 步骤：空手挖硝土块
  - 预期：掉落 2–4 个硝土。

- [ ] **C7 时运不影响**
  - 步骤：用时运 III 镐挖 50 个硝土块
  - 预期：每次仍为 2–4 个，**不会超过 4**。

- [ ] **C8 精准采集**
  - 步骤：用精准采集镐挖硝土块
  - 预期：掉落 `piranport:saltpeter_block` 本身。

- [ ] **C9 爆炸掉落**
  - 步骤：用 TNT 炸硝土块/矾土矿
  - 预期：按 `explosion_decay` 正常掉落（可能减少），无异常。

- [ ] **C10 掉落上限保证**
  - 步骤：连续挖 200 个硝土块，记录最大值
  - 预期：最大值为 4；否则配方 4 硝土 → 1 硝土块会失衡。

## E. 熔炼与高炉

- [ ] **E1 矾土熔炼**
  - 步骤：熔炉烧 1 矾土
  - 预期：产出 1 铝锭；时间 200 ticks（10 秒）；经验约 0.35。

- [ ] **E2 矾土矿熔炼**
  - 步骤：熔炉烧 1 矾土矿
  - 预期：产出 1 铝锭；时间 200 ticks；经验约 0.7（比矾土多）。

- [ ] **E3 高炉矾土**
  - 步骤：高炉烧矾土 / 矾土矿
  - 预期：产出 1 铝锭；时间 100 ticks（5 秒）；经验同上。

- [ ] **E4 钢锭**
  - 步骤：高炉烧 1 铁锭
  - 预期：产出 1 钢锭；100 ticks；经验约 0.3；熔炉不能烧。

- [ ] **E5 钢粒**
  - 步骤：高炉烧 1 铁粒
  - 预期：产出 1 钢粒；**12 ticks**（0.6 秒）。

- [ ] **E6 钢块**
  - 步骤：高炉烧 1 铁块
  - 预期：产出 1 钢块；**900 ticks**（45 秒）。

- [ ] **E7 原油 → 燃油**
  - 步骤：熔炉烧 1 原油桶；高炉烧 1 原油桶
  - 预期：产出 1 燃油桶；熔炉 200 ticks / 高炉 100 ticks；经验约 0.3。
  - 注意：输入桶被消耗，输出本身是带桶的燃油桶，不额外返还空桶。

- [ ] **E8 经验值**
  - 步骤：清空经验条，分别烧 10 个上述配方
  - 预期：经验按 0.35 / 0.7 / 0.3 累积（允许 ±1 点显示误差）。

- [ ] **E9 燃料槽兼容**
  - 步骤：把原油桶/燃油桶放入熔炉燃料槽
  - 预期：可识别为燃料（见 F 节）。

## I. 流体

- [ ] **I1 放置**
  - 步骤：手持原油桶/燃油桶右键地面
  - 预期：放置对应流体方块，桶变空桶。

- [ ] **I2 装桶**
  - 步骤：手持空桶右键流体源方块
  - 预期：获得对应原油桶/燃油桶。

- [ ] **I3 流动**
  - 步骤：在平地上倒一桶
  - 预期：流动范围约 4 格（`slopeFindDistance=2`、`levelDecreasePerBlock=2`），流动速度偏慢。

- [ ] **I4 无伤害/窒息**
  - 步骤：潜入原油/燃油 30 秒
  - 预期：不受到伤害、不窒息；`canSwim=false`，观察是否沉底/无法上浮（记录实际表现）。

- [ ] **I5 渲染**
  - 步骤：观察静态与流动贴图
  - 预期：半透明、有颜色 tint；流动方向正确；无紫黑。

- [ ] **I6 不与水/岩浆反应**
  - 步骤：把原油倒在水边、岩浆边
  - 预期：不生成圆石/黑曜石/石头，不发生流体转换。

- [ ] **I7 不点燃**
  - 步骤：在原油旁点火/放岩浆
  - 预期：不燃烧、不蔓延（当前设计）。

- [ ] **I8 两种油不混合**
