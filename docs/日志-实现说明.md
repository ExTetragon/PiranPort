# 日志输出

记录点、级别和字段见[日志输出清单](日志-输出清单.xlsx)。Java 控制台的日志器、文案、验收标记和异常输出统一由 `logging/ModLog` 管理，主类只挂接监听；Python 验收工具保留各自的命令行结果输出。

`config/piranport-common.toml` 的 `debugLogging` 默认 `false`。开启后仅将 `piranport` 日志器调整为 DEBUG，关闭后恢复 INFO；配置重载立即生效，不改根日志器、Minecraft 或其他模组的级别。INFO、WARN、ERROR 不受开关影响。配置加载和变化记录六项当前值，同值重载不重复输出。启动摘要只在服务端启动时输出，数据和标签重载记录十舰／工厂配方的实际数量，不逐项列出。

制造事务记录维度、坐标、任务标识、目标、开工费用、完成产量、取消退款及燃油销毁量。找零与退款分别记录进入缓存、玩家背包和掉落的数量。正常缺料、产物未取、图纸不匹配、退款掉落均为预期结果，不升为警告。菜单记录开工、确认取消和容器操作结果；筛选、输入、普通浏览和过期网络包不输出。任务条件改变时记录暂停或恢复，不逐 tick 记录进度。

服务端方块实体 `onLoad` 记录任务恢复；非空任务字段未能恢复或目标目录已失效时警告一次。GUI 网络同步使用的状态读取不触发恢复日志。物品、流体和配方 Codec 已由 Minecraft／NeoForge 报出的错误不重复包装，也不增加旧版本迁移或日志专用的存档字段。

燃料桶只在实际连接、断连、切轴和成功容器交互时记录。核心栏位、熟练度及装备耐久仅记录实际变化，查询和模拟无输出。原版耐久路径在实际写入处记录，避免未破坏附魔抵消耗损后仍报告扣耐久。图纸在玩家合成完成和登录补判结束后记录，配方匹配与预览不输出；原版合成器没有对应的玩家合成事件，暂不额外拦截它的完成回调。

流体能力按事件类型每 100 个服务器 tick 汇总成功操作次数和流量，油湖／硝土按类型汇总尝试与成功次数。正常 20 TPS 下约为 5 秒，服务器退出时输出剩余汇总；关闭调试即丢弃尚未输出的诊断计数。固定事件桶不保存坐标集合或随世界规模增长的条目。模拟、拒绝的转移和逐候选预检不计入成功转移量，不输出完整 NBT 或持续扫描背包。

开发运行默认 INFO；确需框架 DEBUG 和注册明细时用 `-PverboseGameLogging=true`。该 Gradle 选项独立于模组调试开关。统一入口保留 `PIRANPORT_*`、`TOOLTIP_SCREENSHOT`、`UI_SCREENSHOT` 的原始解析格式；验收错误统一 ERROR 并保留堆栈，报告写入错误不再静默吞掉。测试类及资源继续排除在发行包外。

验证范围和产物见 [validation.json](../build/logging-20261025/validation.json)。日志 GameTest 覆盖调试开关与根日志级别、WARN 保留、模拟静默、流体两种抽取重载的单次计数、服务器载入警告限频、制造状态变化及耐久实际提交；其余记录点随既有制造、桶、核心和装备回归执行。
