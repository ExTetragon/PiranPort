# 美术连续修订版本合并说明

2026-10-31起，同一美术素材的相邻连续修订合并为一次版本递增。0.1.112之后取消20次重复美术升版，当前版本由原0.1.144归并为0.1.124，累计87项功能实现、37项修复。现有贴图、模型和游戏行为继续采用归并前的最终结果。

材料首版包含铝锭和钢锭，后续三面亮棱一轮同时修改两者，形成相邻且改动对象交叠的连续段。矿物首版后紧接矾土块修订，因此归入同一次交付；其后从矾土块切换到硝土块，另起一个连续修订段，只保留硝土块第一次修正的递增。

油品配色、动画接入和桶物品外观是三项独立交付，不属于同一贴图的反复细调。原油透明度修正前一项是桶物品贴图，已切换素材，因此单独保留。燃料桶动态液位、内衬接缝及UV裁剪涉及新增行为或实际模型／渲染逻辑缺陷，也保留独立计数。

## 后续计数规则

- 同一素材的相邻连续修改只递增一次。首次交付计一项，紧接着调整颜色、轮廓、尺寸、位置、明暗、透明度或像素细节时，沿用该版本，不因对话轮次、重绘、保存、出图或构建次数再次递增。
- 同批首版素材与其紧接、改动对象交叠的修订可归入同一段；切换到没有共同改动对象的素材，或插入独立功能／代码修复后，结束当前连续段。
- 新增动画接入、动态液位等实际能力，或修正流动、连接几何、运行时UV算法等独立缺陷，仍按实际交付计数。纯贴图细调不再另计为独立bug修复。
- 当前连续美术段是蓝图图标，使用0.1.124。其后紧接的蓝图或舵轮细调继续使用0.1.124；下一项独立交付才递增至0.1.125。
- 本次规则维护不计功能或修复项。0.1.111及之前的交付计数保持原基线，后续以本次归并结果为准。

## 历史证据与版本标签

历史JAR、截图、验收报告、修订目录及素材引用继续保留生成时的原版本标签，避免改变已经发生的验证事实。现行工程配置、README、开发日志交付计数与当前素材说明使用新基线；查看旧报告时按上表对应。

例如，新0.1.124表示蓝图交付；旧报告中的原0.1.124仍表示硝土块色阶修订。蓝图所引用的原0.1.136小舵轮继续通过`revisions/16px-v2`定位，不把历史素材引用替换为含义不同的新标签。
