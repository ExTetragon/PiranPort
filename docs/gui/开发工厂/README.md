预览选择与实际任务独立；快修8个作为一批产出，未取走时按钮可点但不能再开工。维修标签锁定。筛选只有类别和文字，不含国籍或细分。其他字体、缩放及第三方界面扩展仍需人工复核。


标题采用与船坞一致的蓝色斜切带、蓝色下沿及右侧双斜纹，标题带按默认字体实际宽度留白。页面直接复用船坞底纹及18×18槽位纹理；预览保持96×48并补入细网格。储罐使用相同凹框、金色渐变和刻度；上下区域及材料／玩家物品栏之间均采用连续细线。所需材料凹面仅包围标题和四行资源，不包含开发按钮、任务名、图纸或产物。

开发／取消按钮沿用船坞的金属渐变、状态颜色、边框和双斜纹；现有交互与槽位坐标保持一致。实际截图已复核非整数缩放下的底纹接缝及中英文标题，验证见[本轮报告](../../../build/factory-gui-style/validation.json)。

分类说明已与装备提示统一，类别及适用细分共用一行。完整悬浮与细分实例见[分类说明归档](../分类说明/README.md)，当前验证见[报告](../../../build/classification-text/validation.json)。
