# PiranPort GUI 风格规范

> 2026-10-25 确认。船坞和开发工厂统一采用深海军蓝菱形底图、局部技术线边框和蓝色斜切标题。后续 GUI 优先沿用本规范；具体界面的新要求优先。

## 当前基线

- [船坞定稿](船坞-GUI-定稿.png)：348×252，模型预览60×86。
- [开发工厂定稿](开发工厂-GUI-定稿.png)：384×252，物品预览96×48。
- [可编辑布局示意 SVG](制造界面-风格源.svg)：标题、净底控件和槽位结构；边框花纹以高精度PNG为准，不由此SVG生成。
- [定稿素材与生成记录](GUI-定稿来源.json)、[船坞功能说明](船坞-GUI-预览说明.md)。

两张定稿统一采用开发工厂的蓝色标题底带、船坞的边框花纹。生成预览用于确认外观，文字、数值、字体与交互坐标以游戏实现为准；旧状态图和旧交互 SVG 继续用于说明功能，不作为当前配色基线。

## 窗口、边框与底图

窗口之外显示 Minecraft 游戏世界及原版界面遮罩，不绘制自定义背景、菱形、技术线或其他装饰。突出窗口的图标标签属于 GUI 本体。

窗口内分为三层：

1. **底图**：深海军蓝暗角与柔和钢蓝亮部，少量大尺度半透明交叠菱形、稀疏交叉细线。图案低对比，不铺细密线路，不使用大面积粗斜纹或明显颗粒。
2. **边框**：外缘结构线统一为1逻辑像素、`#397FA6`，四边与标签轮廓同色，不叠加贴图自带的亮边。技术线纹集中在标题右端、底部两角和右下内沿。统一使用短线、小方框、三个竖排小菱形、成对斜纹；比底纹清晰，比功能高亮暗。装饰完全位于窗口内部，不扩宽边框，不挤占栏位。
3. **内容**：预览、列表、材料说明和物品槽使用净底凹框，遮住背后的纹样；文字和可操作状态优先于装饰。

不同尺寸页面共用同一张高分辨率边框底纹。取样时裁去原图外周3逻辑像素的生成描边，以原48像素边角分界作九宫格：四角剩余45×45逻辑像素保持原比例，边段与中央适配窗口内部，外缘另画结构线。边角随窗口定位，不重复平铺或切碎花纹。上下分隔线及材料／物品栏分隔线保持连续细线，不延伸装饰进入内容区。

## 标题与标签

标题统一采用开发工厂定稿的蓝色渐变斜切底带，右端带窄暗色过渡，下面接连续细蓝线。底带从外框内侧第1逻辑像素开始铺满，与上、左结构线直接衔接，不能露出额外深色窄条。按默认字体测得的标题宽度留白，保持相同高度和切角规则。选中图标标签与标题带衔接，连接处不留下灰线或断层。

标签只显示图标，名称通过悬浮呈现；锁定功能保持灰暗和锁标识。保留进行中橙色点、产物待取绿色点，空闲不显示状态点。

标题切角、标签切角及按钮斜纹采用竖2横1，约63.435°。边框花纹以合成PNG中的统一斜向构图为准；底图菱形与交叉细线沿用参考图的大尺度构图，不作为控件切角使用。

## 控件、文字和排布

- 全部文字采用 Minecraft 默认字体，不从生成预览中截取文字、数值或图标作为游戏贴图。
- 中文分类采用紧凑中点“·”和全角括号“（）”；英文采用“ · ”和半角括号。舰船为“船型·舰种·国籍”，装备为“类别·适用细分”，无细分仅显示类别。列表、预览与悬浮一致。
- 可用列表条目为较浅的凸起蓝灰底，缺料条目较暗。选中轮廓独立表达浏览选择，缺料条目被选中时仍保持灰化。
- 所需材料凹面只围住标题及资源行；按钮、任务名、图纸、进度箭头和产物分别呈现。缺料时对应整行标红。
- 材料缓存与玩家物品栏分别按实际槽位范围绘制凹面；槽距18×18。分隔线两侧留白均衡，保留已确认的储罐与材料缓存间距。
- 列表顶部筛选条固定，覆盖包含滚动条的完整宽度。无图纸时保留“显示全部”和搜索入口。筛选图标有条件时变亮并加漏斗，左键编辑、右键清除。
- 长名称按默认字体实际宽度截断并显示“…”；先预留任务状态后缀，悬浮显示全名。不通过缩小字体或挤占相邻栏位解决溢出。
- 确认弹窗按内容收紧、逐行居中；动态提示不移动确认按钮。筛选和确认弹窗沿用同一净底、边框与按钮配色，避免在文字后铺花纹。

## 实现与资源

船坞与开发工厂共用 `client/gui/ManufacturingGuiStyle`，分别保留348×252、384×252的布局和原交互坐标；客户端渲染类不进入服务端公共路径。

`textures/gui/manufacturing_background.png`由imagegen参考舰R `common_bg_2`及已确认定稿合成边框和底纹，1547×1016像素，对应384×252逻辑画布，约4倍细节。平滑取样并裁去外周生成描边，按九宫格显示；不再用整数GUI像素重画小菱形与斜纹。精确的外缘结构线、标题、文字、网格、槽位、进度和按钮独立绘制，功能位置不变。生成记录见[高精度贴图说明](边框高精度贴图-生成说明.json)。旧船坞整页贴图和工厂窄条重复取样路径已移除。

新增 GUI 保存 PNG 和可编辑的布局或风格源；新风格确认后同步本规范、定稿和项目指引。功能状态归入各自状态目录，历史截图保留其版本和适用范围。
