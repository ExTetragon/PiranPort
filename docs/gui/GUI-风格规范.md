# PiranPort GUI 风格规范

> 2026-10-24 确认，以当前船坞 GUI 定稿为视觉基线，沿用已确认的舰R灰蓝风格。后续新增或调整本项目 GUI 时优先采用本规范；具体界面的新要求优先。

风格参考舰R的通用控件与建造界面，采用石墨灰蓝面板、亮蓝重点色、斜切角和克制的金属质感。以上文件记录已确认的视觉设计，船坞建造已实现，强化和改造标签暂时锁定。各界面按自身功能安排布局、尺寸及槽位数量。

## 配色与质感

大面积底色保持较低饱和度，亮蓝集中用于当前选中页、标题带和选中边框。通过明度、边缘高光和阴影区分层级。

| 用途 | 基准色 / 渐变（上 → 下） |
|---|---|
| 外部背景 | `#0F1724` → `#0D1A29` |
| 主面板 | `#2E3945` → `#222D38` |
| 蓝色标题带 | `#3299E7` → `#176BB0` |
| 选中标签页 | `#4BA9E8` → `#3299E7`，底部与标题带衔接 |
| 可操作的浅灰凸起按钮 | `#6D7C89` → `#52616E` |
| 锁定条目底色 | `#283440` → `#202B35` |
| 凹陷槽位 | `#304151` → `#243443` |
| 主要 / 次要 / 禁用文字 | `#EDF0F5` / `#BECDD9` / `#8998A7` |
| 缺料文字 / 行背景 | `#EE7A73` / `#4F3239` → `#462C34` |
| 燃油液面 | `#C09B45` → `#967129` |
| 建造中 / 产物待取状态点 | `#E7A251` / `#7DCC91` |

面板使用低对比细暗纹及轻微渐变；按钮保留上缘高光、下缘阴影，槽位呈凹陷感。储罐用液面高光与明暗变化表现流体。纹理强度服从文字和槽位的可读性。

## 控件与文字

- 全部文字采用 Minecraft 默认字体，字号和像素边缘保持一致。
- 分类说明中文采用紧凑中点“·”，两侧不留空格，细分括号采用全角“（）”；英文采用“ · ”和半角括号。舰船统一为“船型·舰种·国籍”，装备为“类别·适用细分”，无细分则只显示类别。列表、预览说明和悬浮保持一致。
- 标签页采用较低的斜切角图标卡片。选中页的蓝色底与标题带连续衔接，连接处融为一体；未选中页保持较暗的灰蓝底和细边框。
- 标签页只显示图标，名称在悬浮时出现。设计预览中的图标和人物模型沿用占位符。
- 装饰斜边统一采用竖向 2、横向 1 的比例，斜边与水平线夹角约为 **63.435°**；标题带、标签切角、页角和按钮斜纹遵循同一倾角。
- 可操作条目使用稍浅的灰色凸起底；锁定条目压暗并降低文字明度。选中边框与可操作状态分别表达，选中的缺料条目仍保持灰化。
- 缺少材料时，相关材料整行标红。状态已有清晰视觉区分时，文字保持精简，必要的具体原因放入悬浮提示。
- 列表顶部的筛选控件固定显示，覆盖含滚动条的列表全宽，和可滚动条目分开；列表为空时仍保留查询入口。
- 长名称按默认字体实际宽度截断并显示“…”；先预留状态后缀，悬浮显示全名。文字在自身区域内排布，不通过缩小字体或推开相邻栏位解决溢出。

## 排布与沿用方式

按槽位网格统一对齐，保持相邻栏位间距一致、分隔线两侧留白均衡。后续界面优先沿用上述配色、质感、字体、控件状态和装饰角度，再依功能调整排布。

新增预览保留 PNG 和可编辑 SVG；发生新的风格确认时，同步本规范及项目指引中的基线引用。定稿后清理中间布局版本；同一套最终布局的功能状态放入 `状态预览/`，选定参考音效及来源放入 `音效/`。船坞已确认的交互规则与待讨论项见[定稿与功能设计说明](船坞-GUI-预览说明.md)。

## 弹窗与筛选状态

确认弹窗按实际文字、换行与按钮尺寸计算宽高，标题和说明逐行居中，动态提示不得移动已显示的确认按钮。搜索入口采用放大镜，有筛选时亮蓝并叠加小漏斗，以颜色和形状共同标明；左键编辑，右键清除条件，悬浮说明快捷操作。多选按钮沿用灰蓝底和亮蓝选中边框，所有文字保持默认字体。


## 制造界面的实现沿用

船坞与开发工厂的标题使用蓝色渐变斜切带、蓝色下沿及右上双斜纹，标题宽度按默认字体实际测量留白。主面板沿用船坞细暗纹，预览区使用凹框和细网格，槽位直接复用相同纹理；储罐保留金色液体渐变与右侧刻度。分隔线使用连续细线，保持线两侧的平衡留白。

所需材料凹面只包围标题与材料行；操作按钮、任务名和图纸／箭头／产物不围入同一个大框。材料缓存与玩家物品栏的背景按各自槽位范围绘制，按钮保留金属渐变和统一双斜纹。使用纹理分区取样时留出净底纹边距，防止非整数GUI缩放出现相邻边框接缝。
