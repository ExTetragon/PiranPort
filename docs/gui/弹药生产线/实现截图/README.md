高爆弹每次4枚需铜4粒、钢4粒和火药3个；40枚为10次，需求显示铜4锭4粒、钢4锭4粒和火药30个。反舰导弹每次1枚需铜6粒、钢9粒、铝6粒和火药3个。截图展示的是浏览草稿总需求，进行生产不会自动递减该数值；上方缓存与下方当前任务独立。

右栏顶部居中显示“块锭粒可自动转换”，与产量／耗时同色；下方材料槽、箭头和产物槽的上下与组间留白均4逻辑像素。需求悬浮只列模式与实际材料需求。

专用GUI检查完成27项，本轮仅编译服务端GameTest。具体范围见[生产线方案](../../../3.2.4-弹药生产线-实现方案.md)第12节和[GUI报告](../../../../build/ammunition-right-column-20261026/ammunition-ui/summary.json)。其他字体、缩放及真实第三方界面仍需人工复核。旧版“英文单位说明.png”保留为历史截图，以本页链接为当前状态。
