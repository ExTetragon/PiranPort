# 皮兰港 PiranPort

简体中文 | [English](README.en.md)

*「我认为列克星敦就是这个世界的主宰，所有人都应该成为她忠实的奴仆」*

**皮兰港 PiranPort** — 一个面向 **Minecraft 1.21.1 (NeoForge)** 的 **战舰少女R** 主题综合性 mod：玩家可以扮演舰娘，在生存玩法中开采资源、烹饪食物、制作舰装与武器，与主世界、海图副本和深海世界中的深海敌人战斗，并探索独立剧情。内容分为战斗、后勤、剧情三大系统。

> **状态：早期开发，当前版本 0.1.125。** 已有104个注册物品，包含食物、矿物、蓝图、八种弹药和舰装核心，另有15类装备物品，包含21个耐久型号与2种普通消耗品，提供耐久、飞机储油、逐型创造栏和32×32贴图；开发工厂已支持23项配方、图纸预留、取消退款、缓存保存、自动化及类别／文字筛选；快修与损管可堆叠，自动消耗、作战与维修尚未实现。船坞支持单工位全船型建造、逐舰建造、图纸预留、取消退款、混合材料找零、缓存保存和自动化接口，并提供舰R风格 GUI、国籍与多选搜索筛选，方块和物品已接入独立模型及四向轮廓碰撞；战斗行为、正式舰娘模型与快速建造留待后续。核心已有十舰身份、分类收纳、燃油、属性查询、熟练度基础数据和掉落保护；舰娘状态、舰装栏 GUI、熟练度增长与收益仍未实现。

[弹药生产线](docs/3.2.4-弹药生产线-实现方案.md)已实现八项生产配方、枚数转有限批次、逐次扣料、暂停续产、中断收尾、分面自动化及铜粒拆合。需求显示支持单次／总量切换，最后关闭的浏览状态保存到机器。

## 计划内容

皮兰港分为战斗、后勤、剧情三大系统。

### 战斗系统

- **舰装与负重**：舰装核心物品层已实现；舰娘状态、舰装栏与负重留待后续
- **武器**：火炮、鱼雷、飞机、深弹、导弹与火箭弹
- **装备**：装甲、声呐、近战、其他远程武器、盾牌和防具、道具
- **状态效果**：高速规避、经验提升、进水、着火、被发现！、装填加速

### 后勤系统

- **资源**：矾土矿、硝土块、原油/燃油、铝/钢、燃料桶；树木与作物仍在后续计划中
- **军工**：船坞、蓝图、开发工厂、武器合成、弹药合成、装弹
- **烹饪**：海军锅、灶、刀与砧板、石磨、方块食物
- **建筑与装饰**
- **皮肤**：船体模型、武器模型、特殊动作

### 剧情系统

- **NPC**：艾拉、深海
- **遗迹**：传送门、补给站、前哨站、深海基地
- **海图**：出击渠、关卡
- **深海意志世界**：主岛与 Boss、外岛
- **成就**
